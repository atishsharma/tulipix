Trust this desktop

This phone has not seen this desktop's certificate before. Installing it once tells the phone that this desktop is who it says it is — after that the connection is encrypted, there is no warning, and this page never appears again.

Download the certificate

If your phone rejects that file, try the PEM version instead.

Leave this page open — it opens Tulipix on its own the moment the certificate is installed.

Install it

Android

  1. Open Settings and search for CA certificate.
  2. Choose Encryption & credentials → Install a certificate → CA certificate.
  3. Accept the warning, pick the downloaded tulipix-ca.crt.
  4. Come back to this page.

iPhone and iPad

  1. Safari asks to allow a configuration profile — allow it.
  2. Settings → General → VPN & Device Management, open the Tulipix profile and Install it.
  3. Then Settings → General → About → Certificate Trust Settings and switch Tulipix on. iOS needs both steps, and the second one is the one people miss.
  4. Come back to this page.

Linux

Browsers on Linux ignore the system certificate store and keep their own, which is why copying the file into /usr/local/share/ca-certificates changes nothing in Chrome or Firefox. This script writes to the right ones, and needs no root: 

curl -fsSL http://HOST/tulipix-ca-install.sh | sh

Or download it, read it, and run it. Restart the browser afterwards. Needs certutil — libnss3-tools on Debian and Ubuntu, nss-tools on Fedora, nss on Arch.

Windows

  1. Double-click tulipix-ca.crt → Install Certificate.
  2. Store location Current User, then Place all certificates in the following store.
  3. Choose Trusted Root Certification Authorities and finish.

macOS

  1. Open tulipix-ca.pem in Keychain Access, in the login keychain.
  2. Find Tulipix Local CA, open it, expand Trust.
  3. Set When using this certificate to Always Trust.
What this does and does not do. The certificate only lets this phone verify desktops holding the matching private key — which is this machine, and only while the key stays on it. It is not a password and grants no access to anything: the PIN and the paired-device list are still what decide who can see your files. Remove it any time from the same settings screen.
